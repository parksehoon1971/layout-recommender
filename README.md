# 물류센터 레이아웃 추천 시스템 · Unity 프로토타입

대상 버전: Unity 6000.6.8f1

## 실행 방법
1. `git clone`으로 저장소를 받습니다.
2. Unity Hub → **Add project from disk** → 받은 폴더를 선택합니다. 필요한 패키지(Unity UI 등)는 `Packages/manifest.json`에 들어 있어서 처음 열 때 자동으로 설치됩니다.
3. 열린 씬(기본 Untitled 씬도 괜찮습니다)에서 **Play**를 누릅니다.
   씬에 따로 배치할 것은 없습니다. 실행하면 `AppManager`가 자동으로 생성되고, 화면은 모두 코드로 만들어집니다.
4. 이후 업데이트는 `git pull`로 받습니다. Unity가 열려 있어도 자동으로 다시 컴파일됩니다.

처음 열 때 자동 설정 (`Assets/LayoutRecommender/Editor/ProjectSetup.cs`)
- URP와 Input System 패키지를 에디터 버전에 맞게 설치합니다.
- URP 에셋을 만들어 기본 렌더 파이프라인으로 지정합니다. ("Built-in Render Pipeline 지원 중단" 경고가 사라집니다.)
- Active Input Handling을 새 Input System으로 바꾸고 에디터 재시작을 묻습니다. ("Input Manager" 경고가 사라집니다.)
- 다시 실행하려면 메뉴 **Tools → Layout Recommender → 프로젝트 설정 다시 실행**을 누릅니다.

참고
- 한글은 OS 폰트(맑은 고딕 등)를 사용합니다. 글자가 □로 보이면 알려주세요. 폰트 에셋을 넣는 방식으로 바꾸겠습니다.
- 다른 씬에서 자동 실행을 끄려면 그 씬에 `DisableLayoutRecommender`라는 이름의 빈 오브젝트를 두면 됩니다.

## 구현된 것

### 1단계: 골격, 시작화면, 입력 절차
| 화면 | 내용 |
|---|---|
| 시작화면 | 새 프로젝트 시작 / 이전 입력 불러오기 / 종료 |
| 입력 절차 (5단계) | ① 화물 특성(파렛트·토트·카톤, L/W/H, 중량, SKU, 단적) ② 입출고량(일 입출고, 피크 계수, 가동시간, 보관 필요량) ③ 건물 조건(폭·깊이·층고·도크) ④ 설비 선호(자동화 수준, 설비별 사용/제외, 적재 단위에 맞지 않는 설비는 자동 비활성) ⑤ 확인 |
| 입력 검증 | 단계마다 값을 확인합니다. 피크 시간당 처리량, 예상 적재 단수 같은 파생값을 실시간으로 보여줍니다. |
| 저장 | '레이아웃 생성'을 누르면 입력값이 `persistentDataPath/last_input.json`에 저장됩니다. |
| 레이아웃 화면 HUD 틀 | 좌측: 카테고리별 설비 팔레트(보관/운반/이송/인력) · 우측: 선택한 개체의 속성창 · 상단: 시뮬레이션 시간, ▶/∥/■, 배속 · 하단: 진행률과 로그 · 가운데: 건물 크기에 맞춘 3D 바닥 |

### 2단계: 배치안 생성과 자동 배치
| 기능 | 내용 |
|---|---|
| 배치안 생성 | 허용된 보관 방식마다 안을 만듭니다: 선택식 랙(+지게차/작업자), 셔틀랙(+리프트·컨베이어 또는 지게차), 스태커크레인 싱글/더블포크(+P&D 컨베이어). 층고로 적재 단수를, 건물 폭으로 열/통로 수를, 보관 필요량과 피크 처리량으로 규모와 대수를 정합니다. |
| 점수와 추천 | 보관 충족(30) · 처리 충족(25) · 자동화 선호(15) · 투자 효율(15) · 공간 효율(15)로 100점 만점을 매겨 상위 3안을 보여주고 1위를 추천합니다. 셔틀랙은 SKU당 재고가 레인 깊이보다 적으면 활용률을 낮춰 계산합니다. |
| 3D 배치 | 건물 외곽, 구역(입고 도크/대기, 보관, 출고 대기/도크), 도크 도어, 랙(기둥·빔), 크레인 마스트, 컨베이어, 차량, 작업자를 단순 도형으로 그립니다. |
| 자동 드래그 배치 | 추천안을 고르면 좌측 팔레트 아이콘이 화면 위를 날아가 설비 자리에 떨어지는 방식으로 하나씩 배치합니다. 팔레트에 사용 개수(×N)가 올라가고, 하단에 진행률이 표시됩니다. 배속 버튼이 배치 속도에도 적용되며, '배치 건너뛰기'로 바로 끝낼 수 있습니다. 배치가 끝나면 시뮬레이션 시간이 자동으로 시작됩니다. |
| 비교와 속성 | 우측에서 A/B/C안을 눌러 바꿔 볼 수 있고(다시 배치됨), 3D 설비를 클릭하면 속성이 나옵니다. |
| 설비 형상 | 지게차(마스트·포크·오버헤드가드·바퀴), 파렛트트럭, AGV(리프트판·라이다), AMR(토트 선반), 작업자(안전모·조끼), 랙(기둥·브레이싱·빔·칸마다 적재물), 셔틀랙(레일·레인 적재), 스태커크레인(주행대차·마스트·승강대·레일), 롤러 컨베이어, 도크 셔터·레벨러·트럭 |
| 보관 공간 표시 | 배치를 시작하면 보관 구역 외곽(굵은 흰 선)과 랙/셔틀 블록 자리, 칸(슬롯)·레인 구분선이 바닥에 먼저 그려집니다. |
| 화물 표시 | 설비를 배치하는 동안 랙은 비어 있고, 배치가 끝나 시뮬레이션이 시작되기 직전에 재고 수준만큼 화물이 한 번에 채워집니다. |
| 재고 수준 슬라이더 | 우측 패널에서 보관 위치 대비 재고 비율(0~100%)을 조절합니다. 기본값은 보관 필요량의 80%입니다. 바꾸면 랙 화물 표시와 시뮬레이션 재고가 함께 바뀌고, 재고가 없으면 출고가, 위치가 꽉 차면 입고가 보류됩니다. |
| 그림 아이콘 | 좌측 팔레트 아이콘은 각 설비 3D 모델을 렌더링한 그림입니다. 끌어다 놓는 아이콘도 같은 그림을 씁니다. |
| 바닥 경로선 | 파란 선: 입고 경로(도크 → 입고 통로 → 랙 통로/입고대/레인 입구), 주황 선: 출고 경로(보관 → 출고 통로 → 도크). 화살표가 진행 방향입니다. |
| 시뮬레이션 | 배치가 끝나면 자동으로 시작합니다(기본 ×8 배속, 피크 시간 발생률). 트럭 도착분이 도크 앞에 내려지고, 운반 설비가 경로선을 따라 보관 지점으로 나르며, 자동창고는 크레인이 입고대↔랙 사이를 움직입니다. 출고는 반대 방향으로 나가 도크 앞에 모였다가 상차됩니다. 하단에 입출고 완료/대기, 시간당 처리량, 설비별 가동률이 표시되고 우측 패널에 결과가 갱신됩니다. |
| 카메라 | 오른쪽 드래그 회전 · 휠 확대/축소 · 가운데(또는 Shift+오른쪽) 드래그 이동 |

계수(통로폭, 지게차 최대 높이, 단가 등)는 `Planning/LayoutPlanner.cs` 상단 상수에서 바꿀 수 있습니다. 투자비는 비교용 개략값입니다.

## 폴더 구조
```
Assets/LayoutRecommender/Scripts
├─ Core/AppManager.cs          앱 부트스트랩, 화면 전환, 카메라/이벤트시스템
├─ Data/ProjectInput.cs        입력 모델(화물/입출고/건물/설비선호), 검증, 저장
├─ Data/EquipmentCatalog.cs    설비 10종 정의(적용 단위, 점유 크기, 속도, 처리능력 대표값)
├─ Core/InputBridge.cs         새/구 입력 시스템 공통 마우스 입력
├─ Planning/LayoutPlan.cs      배치안 데이터(설비 위치, 구역, 도크, 규모, 점수)
├─ Planning/LayoutPlanner.cs   배치안 생성·규모 산정·점수 (계수는 파일 상단)
├─ World/LayoutWorld.cs        3D 건물/구역/설비 생성, 선택 강조, 등장 애니메이션
├─ World/CameraRig.cs          회전/이동/확대 카메라
├─ World/MeshBuilder.cs        박스/원기둥을 한 메시로 모아 그리는 도우미
├─ World/ModelFactory.cs       설비·화물·도크·경로선 3D 형상
├─ World/IconRenderer.cs       3D 모델을 찍어 팔레트 아이콘으로 사용
├─ Simulation/FlowSimulator.cs 입출고 흐름 시뮬레이션 (경로 이동, 크레인, 지표)
├─ UI/UIFactory.cs             코드로 UGUI를 만드는 도우미, 테마 색
└─ Screens/
   ├─ ScreenBase.cs
   ├─ StartScreen.cs
   ├─ InputWizardScreen.cs
   └─ LayoutScreen.cs          레이아웃 화면: 팔레트, 배치안 비교, 자동 드래그 배치, 진행률
```

## 다음 단계
- 3단계: 시뮬레이션 정교화(교대·피크 패턴, 차량 간섭/혼잡, 크레인 사이클 정밀화), 안별 시뮬레이션 결과로 추천 보정.
- 4단계(선택): 사용자 드래그 배치 수정 후 재시뮬레이션.

설비의 처리능력과 점유 크기는 프로토타입용 대표값입니다. `EquipmentCatalog.cs`에서 고칠 수 있습니다.
